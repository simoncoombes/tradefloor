A reproducible market for testing agents

Run a trading agent against a market that reacts to it. Orders match against real order-book depth, so the agent pays for the size it takes and moves the price it trades at. The same seed gives the same market on every platform, so a result you publish is a result someone else can re-run.

pip install pretium cargo add pretium

# you name the companies yourself
u = pt.Universe([
    pt.Instrument("AMZN", "technology",
        initial_price=397.17, eps=12.55,
        book_value_per_share=20.19,
        shares_outstanding=5.1e9),
    # GOOGL, MSFT, AAPL, NVDA alike
])

Three inputs define a market

A universe of companies, a macro state for day zero, and a seed. Same three, same market, on every platform.

The economy runs itself

Every close advances it. The economy updates, the cycle can turn, and the central bank acts. VIX moves most days. The policy fields step on the meeting calendar.

Every move is labelled

The simulator computed each price, so it can say why. Nine factor contributions sum to the move. The residual is near 1e-16.

WHY IT EXISTS

History happened once

A backtest replays a recording. It cannot tell you what would have happened had the agent traded differently, because the prices in it were set by people who never saw the order. Size is free, the market never reacts, and the same run gives the same answer for the wrong reason.

A market that computes its own prices can answer those questions. It can be re-run from a seed, driven through a crisis on demand, forked at a decision point, and asked why a price moved — because it did the moving. What it cannot do is tell you what a real market will do next, and this site is explicit about where that line falls.

WHAT YOU GET

Five properties, each of them checkable

Every one of these has a page behind it showing the measurement or the mechanism. None of them is a claim about how the simulator compares to anything else.

Deterministic

The same universe, macro state and seed give the same market on Linux, macOS and Windows, digit for digit. Every release checks it across five wheel targets and a disagreement stops the release.

Real execution

An agent submits orders to a limit order book and is filled at the levels it consumes. It is not handed a price and told what it would have got.

Its own impact

Taking size moves the price the agent trades at. Run the same seed with the orders and without them and the difference is what the trading cost, priced against the market where it never traded.

Observable

Nine factor columns sum to each price move, so the simulator can say why a price went where it did. The residual is near 1e-16.

Measured, and bounded

Fourteen statistics against the ranges real equities hold, a certified horizon of 252 days, and five named gaps that each end in a rule about what the market must not be used for.

Reinforcement learning, model-driven agents over MCP, execution-cost research, market-making, scenario studies and agent benchmarking all run on the same engine. The market is the first environment it ships with, not the limit of what it is for.

STEP 04 - DRIVE IT

Three ways to drive it

A model can study the market from outside, or trade inside it. A policy can train against it. An algorithm you wrote can be scored on it. Cheapest first.

Agents over MCP

Nothing you write. Claude or another model calls the simulator as a tool and reads the answers. Eleven tools, everything composed as data.

Reinforcement learning

Passes gymnasium's env_checker. Actions are target weights in [-1, 1]. Reward is measured after the market moves, so it already carries the cost of the agent's own footprint.

import pretium.gym as ptg

env = ptg.TradingEnv(universe=u,
    seed=42, days=20)
obs, info = env.reset(seed=42)
obs, r, done, trunc, i = env.step(a)

Your own trade logic

A TWAP, a VWAP, an iceberg, or your own logic. Any object with an act method will do. The observation is narrow on purpose. It shows only what a real trader can see.

class Mine:
    def act(self, obs):
        return {"AAA": 0.2}

pt.tca.analyse(Mine(), seed=42,
    universe=u, days=5)

Ten agents, one market each

Hand evaluate a dict of ten agents and each one runs in its own copy of an identical world: same seed, same roster, same macro path. Your algorithm, a trained policy, an LLM agent and the five baselines land in one table.

Then rank repeats that across seeds and separates them with a paired sign test. The Oracle reads the true mispricing and says so. Read it as a reference point, not a ceiling: it spends the same gross on a naive rule, and mean-reversion beats it on 5 of the 12 markets.

EACH IN ITS OWN COPY

Ten agents means ten private engines, so nobody eats another agent's depth. That keeps the comparison clean. To put them in one book, build an arena.

agents = pt.reference_agents(seed=3)
agents["mine"] = Mine()
agents["policy"] = TrainedPolicy(net)

scores = pt.evaluate(
    agents, seed=7, universe=u, days=10)

ranking = pt.rank(
    lambda: dict(agents), seeds=range(12),
    universe=u, days=10, workers=4)
BUILD ON IT

An agent arena

Ten model-driven agents in one order book, trading against each other, with the market maker as the house. The harness does not do this: it gives each agent its own copy of the market, which is what makes a comparison clean. Every part an arena needs is public, so you can build one.

What you would write

{{ a.k }} {{ a.v }} 
# 1. an agent is a model behind act()
class LLMTrader:
    def __init__(self, model, style):
        self.model = model
        self.style = style   # "aggressive"

    def act(self, obs):
        reply = self.model.ask(
            system=self.style,
            book=obs.book,
            position=obs.position)
        return reply["weights"]

agents = {
    "claude-momentum": LLMTrader(m1, "momentum"),
    "gpt-value":       LLMTrader(m2, "value"),
    "twap":            TWAP(minutes=30),
}

# 2. one engine, one book, all of them
engine = pt.Engine(seed=7, universe=u)
books = {n: pt.Portfolio(cash=1e6) for n in agents}

for day in range(days):
    engine.open_market()
    for step in range(steps_per_day):
        flow = {}
        for name, agent in agents.items():
            obs = observe(engine, books[name])
            orders = pt.baselines.rebalance(
                obs, agent.act(obs),
                max_participation=0.02)
            books[name].execute(orders)
            merge(flow, books[name].pending_flow())
        engine.run_session(*clock(step), ticks,
                           order_flow=flow)
    engine.close_market()

What the arena would give you

Agents that pay for each other's size. One agent's sweep takes the depth the next one wanted, and every fill is priced by whoever else was in the book that tick. That is a genuine multi-agent market, and the counterfactual run still works: same seed, no flow, and you can price the whole cohort's footprint.

What it would not give you

A market maker that learns the cohort. The maker and the aggregate flow do not adapt, so the only strategic behaviour in the arena is the behaviour you brought. The realism envelope is also silent here: it was measured on one agent, so a cohort result sits outside what has been certified.

STEP 05 - TRUST THE RESULT

How real is it

Real markets have habits. Prices jump by a typical amount. A calm week often comes after a calm week. Names move together in a panic. This page measures fourteen of those habits, each against the range that real equities hold. The shipped preset lands inside all fourteen over a trading year, and there is no single score, because one number travels further than its caveats.

Good results here do not predict real returns

The price process comes from a known model. A strategy that fits the structure of that model looks excellent and teaches you nothing. A strategy that fails here tells you more, because it broke against a live order book under honest impact costs.

One market is one sample

On the twelve-market grid the docs measure, mean-reversion pools at +0.783 capture and momentum at +0.259, so mean-reversion leads by three times. Paired across the same twelve markets it wins 9 to 3, at p = 0.15. One seed picks the pooled leader eight times in twelve, and what a seed says momentum is worth runs from -0.503 to +0.909.
