API

Core Types

Engine

Engine(seed, universe, macro_state=None, model=None)A market. model is a preset name or a ModelParams; the default is pt-v10.
run_days(n)Advance n trading days. The macro chain steps at every close.
bars(grain="day")OHLCV as Arrow. Four granularities.
truth()One row per instrument per tick: fundamental value, anchor price, mispricing, and seven factor contributions that sum to the move.
pin_macro(**fields)Override the endogenous chain for a field from today onward.
draw_uniform() · draw_normal()Host randomness from the external stream. Never touches the market's sequence.
draws_by_stream()Per-stream draw counts: market, economy, external.
model_fingerprintThe preset's name, or custom-XXXXXXXX. Never both.
state_snapshot()Serialisable engine state, RNG streams included, for Checkpoint.

Universe, Instrument, Macro

Universe.random(n, seed)Generated roster, five names per sector, plausible fundamentals. The universe seed is a separate input domain from the simulation seed.
Universe([Instrument, ...])Explicit roster. A list subclass, and order is contractual: a re-sorted universe is a different market.
Universe.from_edgar(snapshot)Real fundamentals from SEC EDGAR.
universe.fingerprintsha256 over the canonical roster, order included.
Instrument(ticker, sector, initial_price, ...)Fundamentals: shares outstanding, eps, book value, revenue growth, average volume, beta, short interest.
Macro(federal_funds_rate, corporate_bond_yield, vix, ...)Day-zero macro state. Rates are fractional: 0.025 is 2.5%.

ModelParams

ModelParams.from_preset(name, **overrides)A coefficient set. Bit-identical to a shipped preset fingerprints as that preset's name; anything else as custom-XXXXXXXX. Immutable once built.
settable()The runtime-settable surface. Non-settable constants are refused by name.
to_dict() · fingerprintThe full surface, and the hash over it.
model_preset()The compact coefficient table the determinism gate digests.

Scenario: Events and Crises

Scenario().hold(**fields)Pin macro fields at a level: a held VIX 45 is a sustained crisis.
Scenario().ramp(field, start=, end=, over=)Walk a field over a window: an inflation shock, a hiking cycle.
Scenario().step(field, before=, after=, at=)Jump a field on a given day. Pins on one field lie end to end, so spike, plateau and decay compose into one scenario.
Scenario.rate_shock(...) · vix_shock(...) · vol_shock(...)Shape constructors: each builds a whole event in one call.
scenario.table(days) · to_json(days) · from_json(text)Inspect the day-by-day path before spending a run on it; serialise it so a result can cite the exact event.
engine.pin_macro(**fields)The same override, applied directly mid-run. Logged, so the run still replays.

evaluate, tca.analyse, facts.measure and run_many all take scenario=. The guide chapter is Scenarios and crises.

Identity and Reproduction

StrategySpec.momentum(lookback_days, top_k)A strategy as a declarative, versioned, hashable document. A hand-written agent still works; its fingerprint is empty rather than fake.
RunManifest.of(engine, seed, universe, strategy)One shareable document embedding every component with its fingerprint and the expected result digest.
manifest.reproduce()Checks the build's arithmetic behaviourally, replays, and on any mismatch refuses, naming the culprit.
Checkpoint · branch(...)Freeze a market mid-run; fork two futures from an identical state.
GameRng(seed, sequence)The PCG32 generator itself. Public, raw, and the replay surface for pre-split recordings.
