REFERENCE

The Nine Components

Every tick's change in mispricing is broken into nine components that sum to it. These are the names the truth table uses, the values explain_price_move returns, and the closed set an agent's explain must answer from. The crate calls them S_COMPONENT_KEYS; the runtime list is Engine.FACTORS.

The Set

In order. The first three are the model’s own dynamics; the last four are shocks.

NameWhat it is
reversionThe pull back toward fair value. Mispricing decays at a rate set by its half-life, so this term is negative when a name is above fair value and positive when it is below.
momentumHerding: the fraction of yesterday's re-rating that continues today. Controlled by momentum_theta, and the reason returns trend here.
crowd_leanThe crowd's net flow. It net-buys what trades below fair value and net-sells what trades above, and it also chases yesterday's move. Bounded, so the crowd can never dominate a news day.
company_newsNews priced into this name: its own events at full weight, its sector's at a fraction, market-wide events at a smaller fraction, and a peer's event where peer transfer is switched on.
order_flow_impactThe permanent, information-bearing part of order imbalance. Your own orders land here. The temporary part is not in this column, because it shows up in the price the book settled rather than in the model's target.
short_squeeze_effectForced flow: short squeezes and stop cascades. Fires on high short interest into a rising price, and on cascades in either direction.
random_noiseThe idiosyncratic draw, scaled by the name's beta, its sector's volatility, its size, and the GARCH variance state.

They Sum, and That Is the Point

Difference mispricing_s across two ticks, add the seven columns, and the residual should be around 1e-16. That is what makes this a dataset rather than a commentary: you can check a label against the outcome instead of trusting it.

PYTHON 
import pretium as pt
import polars as pl

engine = pt.Engine(seed=42, universe=pt.Universe.random(20, seed=11))
engine.run_days(5)
truth = pl.from_arrow(engine.truth())

FACTORS = ["reversion", "momentum", "crowd_lean", "company_news",
           "order_flow_impact", "short_squeeze_effect", "random_noise"]

one = truth.filter(pl.col("instrument_id") == 0).sort("day", "tick")
delta = one["mispricing_s"].diff()
summed = one.select(sum(pl.col(c) for c in FACTORS)).to_series()
print((delta[1:] - summed[1:]).abs().max())      # ~1e-16

Where the residual is not zero, the mispricing clamp or a circuit breaker bound. That is worth seeing, and it would be invisible in a summary.

Engine.FACTORS is the same list at runtime, so an agent can validate its own answer against it rather than hardcoding strings.

Scope

It is not a decomposition of the price. It decomposes the mispricing, which is the gap between price and fair value. Everything that moves fair value itself, such as a rate change repricing the discount, is in fundamental_value instead.

And it is per tick, deliberately. A day-level attribution can say order flow moved a price today; it cannot say when, and a label you cannot align to a bar is not a label. A name that did not tick has zeros across all seven, because nothing contributed to a move it did not make.
