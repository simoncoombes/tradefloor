Tables and Schemas

Every column a run gives you, plus the enumerations the rest of the docs refer to.

The Output Tables

All five read zero-copy into polars, pandas, pyarrow and duckdb, and the package depends on none of them. Every table keys its rows by instrument_id, which is the roster index, so roster order matters here as it does everywhere else.

bars

OHLCV. grain="tick" gives close and volume per tick; grain="day" gives open, high, low, close and volume per bar.

ColumnType
dayuint32Day index.
tickuint32Tick index. A tick is a minute, and there are 390 in a day. Tick grain only.
baruint32Bar index within the day. Day grain only.
instrument_iduint32Roster index.
open · high · lowfloat64Day grain only.
closefloat64What the book actually settled.
volumefloat64Shares.

truth

The answer key. Three levels plus the seven factor contributions.

ColumnType
day · tick · instrument_iduint32Keys.
mispricing_sfloat64Log gap between price and fair value.
fundamental_valuefloat64What the company is worth: earnings, growth, the sector anchor, rates. No mispricing in it.
anchor_pricefloat64fundamental_value * exp(mispricing_s): the price the model wanted before the book touched it. So close - anchor_price isolates microstructure, and mispricing_s isolates the valuation gap.
reversion · momentum · crowd_lean · company_news · order_flow_impact · short_squeeze_effect · random_noisefloat64The seven factors, in this order. They sum to the change in mispricing_s.

A name that did not tick has zeros across the seven and keeps its last two level values, because a valuation does not disappear when trading is quiet.

macro

ColumnType
dayuint32Day index. The row carries the values the day traded under; the close then advances the chain.
vixfloat64Takes a new value every day.
federal_funds_ratefloat64Fractional: 0.025 is 2.5%. Steps at the central bank's meeting calendar.
corporate_bond_yieldfloat64What equities discount off.
inflation_rate · unemployment_rate · gdp_growthfloat64The Taylor/Phillips/Okun loop's state.
qe_pe_boostfloat64Valuation support from policy.
fear_greed_indexfloat64Sentiment level.
universe_stressfloat64Remembered stress. Ratchets up on a shock and decays over weeks, which is what keeps correlation elevated after an event.

fills

ColumnType
day · step · tick · instrument_iduint32When and what. step is the run-wide decision index.
quantityfloat64Shares. Signed.
pricefloat64Average fill price.
worst_pricefloat64The worst level you reached. The distance from price is how far you walked the book.
notionalfloat64Traded value.

book

ColumnType
day · tick · instrument_iduint32Keys.
sideuint32Bid or ask.
leveluint32Depth index from the touch.
price · sizefloat64The resting quote.

Granularities

bars(grain=) takes "tick" or "day". Both also accept a day= filter, and tick grain accepts minutes= to aggregate into bars of that many minutes, which is where intraday grains come from.

StrategySpec Grammar

A spec is a JSON document and SPEC_VERSION is currently 1. Adding a signal kind or a cadence extends the grammar without changing what existing specs mean, whereas changing what an existing kind ranks would be a new version.

JSON 
{
  "spec_version": 1,
  "signal":    {"kind": "momentum", "lookback_days": 1.0},
  "portfolio": {"top_k": 5, "gross": 1.0},
  "execution": {"max_participation": 0.02},
  "cadence":   "step"
}
Field
signal.kindOne of hold, random, momentum, mean_reversion, oracle, blend.
signal.lookback_daysOn momentum and mean_reversion. Days only, never steps, because a step is a harness artifact. Default 1.0.
signal.componentsOn blend: a list of {kind, weight, lookback_days?}. Blendable kinds are random, momentum, mean_reversion and oracle. Ranks combine first, then top_k selects from the blended ranking.
portfolio.top_kHow many names to hold. Applies to the ranked kinds only. Default 5.
portfolio.grossGross exposure. Default 1.0, or 0.5 for random.
execution.max_participationCap on any order as a fraction of average daily volume. Default 0.02, or 0.05 for hold.
cadence"step" re-decides at every decision point; "daily" only at each day's first step. hold must be "step".
seedRequired when the signal contains random, and refused otherwise.

oracle is privileged: it reads the true mispricing. It declares itself as such, which is why it is a reference rather than a competitor.

What the grammar cannot express: path dependence, conditional logic ("go flat if drawdown exceeds X"), custom signals, and anything reading engine internals except the oracle. Those need a Python agent, and such a result is reproducible by citing code at a commit rather than by a fingerprint.

Exceptions

Nearly everything raises pt.ValidationError, with a message naming the specific thing that was wrong. These are the refusals worth knowing about in advance.

WhereWhat it refuses
envelope.checkA statistic name that is not a key of facts.REAL_MARKETS. A silently dropped name would be a silently granted certification.
envelope.intervalsFewer than two panels. A spread over one observation is not a spread.
atlas.axes_forA parameter that ships at zero and has no explicit range; a ranges or log key not in names; a duplicated name. It warns, rather than refusing, when a range excludes the preset's own value.
atlas.planFewer than 8 samples.
Survey.sensitivityFewer than 8 usable rows, or an output no row measured.
Survey.profileFewer than three rows per bin.
Survey.attributionA vector value outside the surveyed range (extrapolation), a parameter set on one side only, or a parameter that was not surveyed.
Survey.confirmAny seed shared with the survey or between blocks, and a survey with no seed record at all. An empty list is the absence of a record wearing the key.
ModelParams.from_presetAn override of a compile-time constant, by name. Accepting one the engine would ignore would make the fingerprint a lie.
ScenarioChaining a shape constructor onto a built scenario; a compare() baseline that realises the same path as the scenario.
RunManifest.reproduceA build whose arithmetic does not match the manifest's. It names the culprit rather than replaying a different market.
Checkpoint restoreA pre-split snapshot with three RNG numbers instead of nine, naming the era. It cannot be continued bit-exactly.
InstrumentA short_interest between 0 and 1 on a real share count, and an unknown sector key.
loss.band_distance_lossA missing or zero noise scale. An unweighted sum is a choice, and it will not make it by accident.
