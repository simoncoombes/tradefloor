GUIDE

Running a Market

Build a universe, run a market, test a strategy. For most users this page is the whole library.

Why Not Just Backtest

History only happened once, so a backtest can only tell you what your strategy would have earned on that one path, and the tape ignores you no matter how much you buy. Here your orders hit a real book and pay for it, and you can run the same year a thousand times over with different decisions, which is how you separate skill from luck.

What Defines a Run

A universe is the list of companies and their fundamentals. A macro state sets rates, inflation and the business cycle on day zero. A seed fixes every random number. Give it the same three and you get the same market.

PYTHON 
import pretium as pt

universe = pt.Universe.random(108, seed=7)
macro = pt.Macro(federal_funds_rate=0.025,
                 corporate_bond_yield=0.052, vix=16.0)
engine = pt.Engine(seed=42, universe=universe, macro_state=macro)
engine.run_days(252)

Three ways to build a universe:

PYTHON 
pt.Universe.random(108, seed=7)          # generated, plausible per sector
pt.Universe([pt.Instrument(...), ...])   # explicit roster
pt.Universe.from_edgar(snapshot)         # real SEC fundamentals
ROSTER ORDER IS CONTRACTUAL

The engine walks instruments in index order and draws random numbers as it goes, so a re-sorted universe is a different market from the same seed. Sorting your tickers alphabetically upstream silently gives you a different world. Use universe.fingerprint to ask whether two universes are the same one.

Reading the Results

Five Arrow tables come out of a run: bars, truth, macro, fills and book, each with its columns listed. polars, pandas, pyarrow and duckdb read them zero-copy, and the package depends on none of them.

The truth table is the unusual one. One row per instrument per tick, with the true value, the mispricing, and nine components that sum to the move with a residual around 1e-16. It says what there was to earn while you were trading. Every column is listed in Tables and Schemas.

Orders Move the Price

Orders match against a real book with price-time priority, so a big order gets worse prices because it ate through the levels that were sitting there, and there is no slippage formula anywhere in the code. Here is the same momentum signal, changing nothing but how often it rebalances:

The Economy Runs Itself

The macro state you pass in is day zero, and the chain advances at every close: economy update, cycle transition, central bank. VIX takes a new value every day; policy fields step at the central bank's meeting calendar; fair value reprices per instrument when the discount rate moves. To impose a path of your own, drive a scenario or pin a field.

PYTHON 
shock = pt.Scenario.rate_shock(start=0.025, end=0.05, over=15)
agents = pt.reference_agents(seed=3)          # or your own, see The Agent Harness
pt.evaluate(agents, seed=7, universe=universe, days=20, scenario=shock)

engine.pin_macro(corporate_bond_yield=0.09)   # overrides the chain from today

Example: Training an RL Agent

Historical data ignores you, so an agent can buy a million shares of a name that trades ten thousand a day and the tape carries on exactly as it did in 2019, which means whatever it learns about sizing is fiction. Here the market pushes back, and every seed gives you a fresh independent episode.

PYTHON 
from pretium.gym import TradingEnv

env = TradingEnv(universe=universe, seed=42, days=20)
obs, info = env.reset(seed=42)
obs, reward, terminated, truncated, info = env.step(action)

Passes gymnasium's env_checker. Actions are target weights in [-1, 1], so a policy skips learning each instrument's price range first. Reward is measured after the market moves, so it already includes the cost of the agent's own footprint.

Example: Measuring Execution Cost

Every TCA vendor approximates the same missing number: what would have happened if you had never traded. Arrival price, VWAP and fitted impact models all stand in for a counterfactual nobody can run on real data. Here you can run it. Same seed, without your orders, and every fill is priced against the world where you never traded.

PYTHON 
ex = pt.tca.analyse(my_algo, seed=42, universe=universe, days=5)
# my_algo is any object with an act() method -- see The Agent Harness

ex.shortfall_bps()      # what your footprint cost
ex.by_step()            # where you paid it
ex.partial_fills()      # what you asked for versus what you got

my_algo is an ordinary agent: any object with an act method, per The Agent Harness. One known boundary: VIX drives the market factor's variance, so the market prices fear of your flow, and names you never touched can move a few basis points through the fear gauge. That is impact, and pinning VIX in both worlds makes the subtraction byte-exact again.

Use More Than One Seed

One market is one sample. Before you call a winner, run the comparison across many seeded markets and check how often the lead actually holds.

PYTHON 
ranking = pt.rank(lambda: pt.reference_agents(seed=3), seeds=range(12),
                  universe=universe, days=10, workers=4)
ranking.separation("momentum", "mean_reversion")   # wins-losses, sign-test p

On the twelve-market grid the agents docs measure, momentum's pooled capture is nearly four times mean-reversion's. Paired across the same twelve markets it wins only 7 to 5, p = 0.77. Its lead lives in how big its wins are, and a single seed picks the pooled leader only five times in twelve.

LIMITS TO CARRY WITH YOU

Momentum can be profitable here for a reason real markets do not supply. Returns trend, because the mispricing process has a herding term with a dial on it. The shipped pt-v3 preset turns that dial well down: return autocorrelation at lag one reads +0.0375 against a real band of −0.08 to 0.06, so it is in band. Earlier presets did not. pt-v1 ships the same knob at 0.25 and measures +0.249, roughly a fifth of it. Either way the dial exists and real markets have no equivalent, so a strategy whose edge tracks it is exploiting the model. Testing Your Edge shows how to check whether yours does. pt-v3: 30 seeds, 40 instruments, 252 days. pt-v1: median of six seeds, Universe.random(40, seed=111), 252 days, sim seeds 1-6.

One venue, no latency, no strategic counterparties. Orders arrive instantly, there is one book per name, and you trade against a market maker and aggregate flow, never against agents that adapt to you.

A Year, End to End

Build a universe, run a year, read the results, score a strategy, then run the same comparison across twelve markets. Each step prints something, so you can check as you go.

PYTHON 
import pretium as pt

# 1. a universe and a market
universe = pt.Universe.random(30, seed=11)
print(len(universe), universe.fingerprint)

engine = pt.Engine(seed=42, universe=universe)
engine.run_days(252)                        # one trading year
print(engine.model_fingerprint)

# 2. what happened, and what was actually true
bars = engine.bars(grain="day")             # OHLCV for every name
truth = engine.truth()                      # true value + what drove each move
print(bars.num_rows, truth.num_rows)

# 3. score a strategy against a fresh market
spec = pt.StrategySpec.momentum(lookback_days=1.0, top_k=5)
scores = pt.evaluate({"momentum": spec}, seed=7,
                     universe=universe, days=10)
print(scores["momentum"].return_pct, scores["momentum"].pnl)
print(scores["momentum"].strategy_fingerprint)

# 4. the same comparison across twelve markets
ranking = pt.rank(lambda: pt.reference_agents(seed=3), seeds=range(12),
                  universe=universe, days=10, workers=4)
print(ranking.separation("momentum", "mean_reversion"))
