## The seven grounded directions, ordered by resonance

The assignment points at candidate 4 of this list. It is my own ordering, so
candidate 1 is what an unrolled run would have shipped.

1. **Normative specification** (IEEE-754 reference grammar). Numbered
   clauses, normative tables, hex bit patterns, shall/must register. Highest
   resonance because the product's differentiator is bit-exactness and a
   specification is the register that proves it.
2. **Data graphics canon** (Playfair, Tufte). The output is data; Playfair
   invented the financial time series; the audience reads charts daily.
3. **Laboratory notebook.** Bound, numbered, ruled, witnessed. Seeds as
   experiment identifiers, which is the reproducibility spine.
4. **Order tickets and tape.** ← assigned. The market's own paper: coloured
   slip stock, typed numerals, printed rules, punched tape.
5. **Scientific preprint.** Figure numbering, marginal notes, footnotes as
   first-class citizens.
6. **ISO / DIN technical documentation.** Part numbering, dimension lines,
   tolerance callouts. Determinism as a tolerance specification.
7. **Roman epigraphy.** The brief's own literal reading, since `pretium` is
   Latin for price. One candidate spent on it, per the rut rule.

Material families spanned: specification, information design, scientific
record, financial ephemera, industrial documentation, epigraphy. Six, against
the minimum of three.

## The rut, kept out of the list

- What this category always ships: the dark terminal docs theme, monospace
  and a neon accent. This is also exactly what the incumbent
  `just-the-docs` `color_scheme: dark` was, so it was the anti-reference
  twice over.
- Its predictable opposite: cream ground, high-contrast serif display,
  terracotta accent.

## The weighing

Challengers fused before judging, on audience identification and product
clarity.

| challenger | verdict |
|---|---|
| Industrial streetwear quote grammar | Fuses poorly. Hazard diagonals and quoted labels fight comprehension, and Read mode needs wayfinding rather than irony. |
| Provenance ribbon | Fuses better than expected: a run's provenance genuinely is seed plus universe fingerprint plus order log, and the ribbon carries known / inferred / disputed. Strong for the reproducibility pages, weak as a whole-site topology, because documentation is not a timeline. |
| Monochrome product marketing canon | Fuses cleanly and would look good, but it is the category default in better clothes, and a Persuade grammar applied to a Read surface. |

## The decision

Presented through the structured question tool as one committed direction
plus the three challengers, each carrying its verdict, with the standing
canon exit available. The user chose the assigned direction, "Order tickets
and tape".

No comp was rendered before building. No image generation was reached for,
so the world went from card to code without a visual approval point. That is
a real gap against the playbook and the reason the fidelity check in the
finish review had to fall back to judging against the contract text.
